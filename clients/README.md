# Clients

This folder contains settings for each client.

## How to add a new client

1. Create a new folder inside `clients/` (example: `clients/acme`)
2. Copy `client-example/.env.example` into the new folder
3. Rename it to `.env` and fill in the real credentials
4. Never commit the real `.env` file
